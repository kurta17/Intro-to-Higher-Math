Concept I · the object

A set is a collection, and nothing more

Definition

A set is an unordered collection of distinct objects, called its elements.

$x \in A$ means "$x$ is an element of $A$"; $x \notin A$ means it is not.

Two notations

Roster — list them: $\;A = \{1, 2, 3\}$

Set-builder — state the rule: $$B = \{\, x \in \mathbb{Z} : x^2 < 10 \,\}$$ read "the $x$ in $\mathbb{Z}$ such that $x^2 < 10$", so $B = \{-3,-2,-1,0,1,2,3\}$.

Unordered, and no repeats $\{1,2,2,3\}$ and $\{3,1,2\}$ are the same set as $\{1,2,3\}$. A set records what is in it, never how often or in what order.
Write $\{x \in \mathbb{Z} : x^2 < 10\}$ on the board and make the room read it aloud in words — "the set of integers x such that x squared is less than ten". They must be able to say it, not just recognise it. Then ask why $-3$ is in it and $\sqrt{5}$ is not: the $\mathbb{Z}$ before the colon is doing work. The no-repeats point looks pedantic and is not — it is exactly why $|\{1,2,2\}| = 2$.
Concept I · the empty set

The set with nothing in it

Definition The empty set $\varnothing = \{\;\}$ has no elements: $x \in \varnothing$ is false for every $x$.
It shows up on its own $\{\, x \in \mathbb{R} : x^2 < 0 \,\} = \varnothing$. Nobody chose this; the condition excludes everything.
Trap · three different things

$\varnothing$ — a set with no elements. $\;|\varnothing| = 0$.

$\{\varnothing\}$ — a set with one element, and that element is $\varnothing$. $\;|\{\varnothing\}| = 1$.

$\{0\}$ — a set with one element, the number zero. Not the same as either.

The box-in-a-box picture is the one that lands: $\varnothing$ is an empty box; $\{\varnothing\}$ is a box containing an empty box, so it is not empty. Draw it. This distinction returns in Session 6 when they build $\mathbb{N}$ from nothing, and it is worth a mark on the midterm every year.
Concept I · the first pitfall

Element of, or subset of?

Definition $A \subseteq B$ ("$A$ is a subset of $B$") means: every element of $A$ is an element of $B$. $$A \subseteq B \iff \forall x\,(x \in A \Rightarrow x \in B)$$
The difference in one line $\in$ relates an object to a set. $\subseteq$ relates a set to a set.
Example · $C = \{\, \{1\},\, 2 \,\}$
  • $\{1\} \in C$ — true, it is listed.
  • $\{1\} \subseteq C$ — false: is $1 \in C$? No.
  • $1 \in C$ — false. $C$ contains $\{1\}$, not $1$.
  • $\{2\} \subseteq C$ — true, since $2 \in C$.
Go through the four lines one at a time and make the room vote before you reveal each. They will get the first two wrong, which is the point — this is pitfall one from the course spec, and it costs marks all term. The fix is mechanical: to test $\subseteq$, take an arbitrary element of the left-hand set and ask whether it is in the right-hand set. To test $\in$, look at the list.
Concept I · the empty set again

Why $\varnothing \subseteq A$ for every set $A$

Proof

By definition, $\varnothing \subseteq A$ means $\forall x\,(x \in \varnothing \Rightarrow x \in A)$.

Take any $x$. The hypothesis $x \in \varnothing$ is false — that is what "empty" means. And yesterday we agreed: an implication with a false hypothesis is true.

So it holds for every $x$, and therefore $\varnothing \subseteq A$. There was never a case to check.

This is vacuous truth Yesterday a curiosity on the notation slide. Today it does real work — it is why $\varnothing$ appears in every power set.
Trap $\varnothing \subseteq A$ always. But $\varnothing \in A$ only if you put it there.
This is the payoff for yesterday's vacuous-truth line, so say so out loud — it is the first time a piece of logic from one session pays a debt in the next. Students resist this proof because it feels like a trick; the fix is to ask them to produce an element of $\varnothing$ that is not in $A$. They cannot, and that failure IS the proof. Pitfall three from the spec, dealt with properly.
Concept I · equality

Two sets are equal when each contains the other

Definition · set equality $$A = B \iff A \subseteq B \;\text{ and }\; B \subseteq A$$ Equivalently: $A$ and $B$ have exactly the same elements.
The method: double inclusion

To prove $A = B$, write two proofs:

  1. Take an arbitrary $x \in A$. Show $x \in B$. That gives $A \subseteq B$.
  2. Take an arbitrary $x \in B$. Show $x \in A$. That gives $B \subseteq A$.
Why this is the whole session The word arbitrary is what makes it a proof: you assumed nothing about $x$, so it holds for all of them.
Stress "arbitrary" hard. The commonest wrong proof in homework is checking $x = 3$ and stopping — that is an example, not a proof, and it is the same error as offering examples for a universal claim yesterday. Say the template out loud in the form they should write it: "Let x be an arbitrary element of A. Then... so x is in B. Hence A is a subset of B. Conversely..."

Concept I · operations

Building new sets from old ones

Union $$A \cup B = \{\, x : x \in A \text{ or } x \in B \,\}$$

"or" is inclusive — $x$ may be in both.

Intersection $$A \cap B = \{\, x : x \in A \text{ and } x \in B \,\}$$

Empty intersection $\Rightarrow$ disjoint.

Difference $$A \setminus B = \{\, x : x \in A \text{ and } x \notin B \,\}$$

In $A$, not in $B$. Not symmetric.

Worked · $A = \{1,2,3,4\}$, $B = \{3,4,5\}$ $A \cup B = \{1,2,3,4,5\}$  ·  $A \cap B = \{3,4\}$  ·  $A \setminus B = \{1,2\}$  ·  $B \setminus A = \{5\}$
Do the worked line on the board with the room calling out elements. The one thing to labour: "or" in mathematics is inclusive, unlike "tea or coffee". Then point at $A \setminus B$ versus $B \setminus A$ and ask whether difference is commutative — they should see immediately that it is not, which sets up the Cartesian product question after the break.
Concept I · operations

Complement and symmetric difference

Complement

Fix a universe $U$. For $A \subseteq U$:

$$A^{c} = U \setminus A = \{\, x \in U : x \notin A \,\}$$
Trap $A^c$ is meaningless without $U$. The complement of the evens is $\{\text{odds}\}$ in $\mathbb{Z}$, but something else entirely in $\mathbb{R}$.
Symmetric difference $$A \triangle B = (A \setminus B) \cup (B \setminus A)$$ In exactly one of them — the "exclusive or" of sets.
Worked With $U = \{1,\dots,6\}$, $A = \{1,2,3,4\}$, $B = \{3,4,5\}$: $A^c = \{5,6\}$, and $A \triangle B = \{1,2\} \cup \{5\} = \{1,2,5\}$.
Always write the universe on the board before writing a complement — model the habit you want. The symmetric difference is the one they have not met; the "exactly one" reading is what makes it click, and it is worth noting it equals $(A \cup B) \setminus (A \cap B)$, which they will prove in homework.
Concept I · pictures

What a Venn diagram shows you

Definition · Venn diagram A Venn diagram draws sets as overlapping regions — one region for each way an element can be in or out of each set.
Example · two circles, four regions In both, in $A$ only, in $B$ only, in neither — that is $A \cap B$, $A \setminus B$, $B \setminus A$ and $(A \cup B)^c$. Every element of $U$ lands in exactly one.
Draw the two circles and label all four regions with the operations from the last two slides — this is the slide where the vocabulary becomes a picture, and it is worth the two minutes. Ask which region $A \triangle B$ is (the two crescents) before you move on. Then hold the thought: the next slide takes the picture away again.
Concept I · pictures

…and why it is not a proof

Trap · a real exam trap

One picture shows one configuration. A claim about all sets is not settled by one picture.

Three sets need $2^3 = 8$ regions, and a hand-drawn diagram routinely omits some. With four, no diagram of circles can show all $16$.

The honest workflow
  1. Draw the diagram to guess the identity.
  2. Write the double-inclusion proof to establish it.
  3. Hand in step 2.
Pitfall two from the spec. Do not ban diagrams — they are genuinely how working mathematicians find the statement. Ban them as the final answer. The four-set fact is the argument that lands: ask the room to draw four overlapping circles showing all sixteen regions, let them fail for a minute, then tell them it is impossible with circles. That is a memorable reason to distrust the picture.

Concept II · the template

Element-chasing, written out

The move

To show $X \subseteq Y$: take an arbitrary $x \in X$, unfold the definitions of the operations in $X$, and deduce $x \in Y$.

Each operation turns into a logical connective: $\cup \to$ or, $\cap \to$ and, $\setminus \to$ and-not.

The skeleton to copy

$(\subseteq)$ Let $x \in X$ be arbitrary. Then [unfold], so [deduce], hence $x \in Y$.

$(\supseteq)$ Let $x \in Y$ be arbitrary. Then [unfold], so [deduce], hence $x \in X$.

Both inclusions hold, so $X = Y$. $\;\blacksquare$

Put this skeleton on the board and leave it there for the rest of the session — every proof today and every homework proof this week is this shape with different filling. The translation table (union-or, intersection-and, difference-and-not) is the entire technique: once the sentence is in logic, the deduction is usually one step.
Concept II · worked proof, first half

$A \setminus (B \cap C) = (A \setminus B) \cup (A \setminus C)$

$(\subseteq)$ — left into right

Let $x \in A \setminus (B \cap C)$ be arbitrary.

Then $x \in A$ and $x \notin B \cap C$.

Now $x \notin B \cap C$ means not ($x \in B$ and $x \in C$) — so $x \notin B$ or $x \notin C$.

If $x \notin B$, then $x \in A \setminus B$; if $x \notin C$, then $x \in A \setminus C$. Either way $x$ lies in the union.

The step to watch Negating "and" produced "or". That single move is De Morgan — two slides away, with a name.
Board example one from the course spec. Do this half live and slowly, in full sentences, and leave it on the board when you turn the slide — the second half is easier to follow with this still visible. The step students skip is the negation: "not (P and Q)" becomes "not P or not Q".
Concept II · worked proof, second half

…and the inclusion back again

$(\supseteq)$ — right into left

Let $x \in (A \setminus B) \cup (A \setminus C)$ be arbitrary, so $x$ is in at least one part.

Case 1: $x \in A \setminus B$. Then $x \in A$, $x \notin B$, so $x \notin B \cap C$.

Case 2: $x \in A \setminus C$. Then $x \in A$, $x \notin C$, so $x \notin B \cap C$.

Both give $x \in A \setminus (B \cap C)$. With the first half: equal. $\;\blacksquare$

Why two cases "Or" hands you one of two situations, not a specific one. Handle each, and both must land in the same place.
Ask the room why the case split is forced before you write it: a union hypothesis tells you $x$ is in at least one part, but not which, so a proof that assumes it is in $A \setminus B$ has covered only half the possibilities. Then close the argument explicitly — both inclusions shown, therefore equal — because students routinely prove both halves and forget to say the conclusion.
Concept II · the named theorem

De Morgan's laws

Theorem · De Morgan's laws For all $A, B \subseteq U$: $$(A \cup B)^{c} = A^{c} \cap B^{c}$$ $$(A \cap B)^{c} = A^{c} \cup B^{c}$$
Proof of the first

$(\subseteq)$ Let $x \in (A \cup B)^c$: then not ($x \in A$ or $x \in B$), so $x \notin A$ and $x \notin B$, i.e. $x \in A^c \cap B^c$.

$(\supseteq)$ Let $x \in A^c \cap B^c$: then $x$ is in neither, so $x \notin A \cup B$. $\;\blacksquare$

In English "Not (even or a multiple of three)" $=$ "not even and not a multiple of three" — your Activity 2 sentence. Negation swaps and with or.
Call back to Activity 2 explicitly: they already proved an instance of this in English without knowing its name. Prove the first law on the board and set the second as a thirty-second exercise — it is the same argument with the connectives swapped, and noticing that is worth more than watching you do it. De Morgan returns in Session 5 for quantifiers and in Session 10 for logic; flag that.
Concept II · the other direction

Disproving a set identity

What a disproof needs An identity is universal. To destroy it, produce one triple where it fails.
Worked · is $A \setminus (B \setminus C) = (A \setminus B) \setminus C$?

Take $A = B = C = \{1\}$.

Left: $B \setminus C = \varnothing$, so $A \setminus \varnothing = \{1\}$.

Right: $A \setminus B = \varnothing$, so $\varnothing \setminus C = \varnothing$.
$\{1\} \neq \varnothing$: false.

Trap

"It failed when I drew it" is not a disproof.

Name the sets, compute both sides, point at the element on one side and not the other — here, $1$.

Set difference is not associative and this is the smallest witness. Make them see the asymmetry: the search for a counterexample is not random, you look where the operations disagree — sets that overlap heavily, or the extremes $\varnothing$ and $A$ itself. Tell them homework has three disprove items and this is the format expected: named sets, both sides computed, offending element named.

Prove it or break it

Activity 3groups of three15 min
Three are true, two are false. Prove by double inclusion, or kill it with named sets and both sides computed.
  1. $A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$
  2. $(A \setminus B) \cup B = A \cup B$
  3. $(A \cup B) \setminus B = A$
  4. $A \triangle A = \varnothing$
  5. $A \cup (B \cap C) = (A \cup B) \cap C$
Share: two groups present, one proof and one disproof. The room checks that the proof says "arbitrary" and the disproof names its element.
True: 1 (distributivity), 2, 4. False: 3 and 5. For 3, take $A = \{1\}$, $B = \{1\}$: left is $\varnothing$, right is $\{1\}$ — it only holds when $A$ and $B$ are disjoint, and asking a group to find that repair is the good follow-up. For 5, take $A = \{1\}$, $B = C = \varnothing$: left $\{1\}$, right $\varnothing$. Do not let a group claim 1 by Venn diagram; that is the pitfall from before the break and this is where it gets tested.
Concept II · ordered pairs

The Cartesian product

Definition · Cartesian product The Cartesian product of $A$ and $B$ is $$A \times B = \{\, (a,b) : a \in A \text{ and } b \in B \,\}$$ Its elements are ordered pairs: $(a,b) = (c,d)$ exactly when $a = c$ and $b = d$.
Ordered, unlike a set $\{1,2\} = \{2,1\}$, but $(1,2) \neq (2,1)$ — the difference that makes coordinates, and tomorrow's functions, possible.
Worked · $A = \{1,2\}$, $B = \{x, y\}$ $$A \times B = \{(1,x), (1,y), (2,x), (2,y)\}$$ $$B \times A = \{(x,1), (x,2), (y,1), (y,2)\}$$
Trap $A \times B \neq B \times A$ in general. Witness: $A = \{1\}$, $B = \{2\}$.
Board example three from the spec. The point to make: $\mathbb{R} \times \mathbb{R} = \mathbb{R}^2$ is the plane they have used since school, and they have been taking ordered pairs for granted for years. Ask when $A \times B = B \times A$ actually does hold — the answer ($A = B$, or one of them empty) is a nice small proof and a good homework item.
Concept II · counting

How big is $A \times B$?

Theorem

If $A$ and $B$ are finite, then $\;|A \times B| = |A| \cdot |B|$.

Proof Every pair $(a,b)$ comes from two independent choices: $|A|$ ways to pick $a$, then $|B|$ ways to pick $b$. Distinct choices give distinct pairs, since pairs match only when both coordinates do. So the count is $|A| \cdot |B|$. $\;\blacksquare$
You have just used the product rule That argument — independent choices multiply — is the foundation of Session 7's combinatorics. Notice it now, so it is familiar when it gets a name.
Verify it on the $2 \times 2$ example from the previous slide before proving it in general — concrete first, then the abstraction, which is the order this cohort needs. Flag honestly that "distinct choices give distinct pairs" is the step doing the real work, and that in Session 7 this becomes the product rule with a proper name.
Concept II · sets of sets

The power set

Definition · power set The power set of $A$ is the set of all subsets of $A$: $$\mathcal{P}(A) = \{\, X : X \subseteq A \,\}$$ Its elements are themselves sets.
Trap Members of $\mathcal{P}(A)$ are related to $A$ by $\subseteq$, but to $\mathcal{P}(A)$ by $\in$. So $\{1\} \in \mathcal{P}(A)$ and $\{1\} \subseteq A$ — both true, different statements.
Worked · $\mathcal{P}(\{1,2,3\})$

Organised by size:

$\varnothing$

$\{1\},\ \{2\},\ \{3\}$

$\{1,2\},\ \{1,3\},\ \{2,3\}$

$\{1,2,3\}$

Eight subsets: $1 + 3 + 3 + 1 = 8 = 2^3$. Both $\varnothing$ and $A$ itself are always in there.

Board example two from the spec — list all eight live, in that order, and make them tell you what is missing when you deliberately leave out $\varnothing$. The rows $1,3,3,1$ are a row of Pascal's triangle; do not explain it, just point at it and say Session 7. The $\in$ versus $\subseteq$ box is pitfall one returning in a harder costume, which is exactly why power sets are where students lose it.
Concept II · the count

$|\mathcal{P}(A)| = 2^{|A|}$

Theorem If $|A| = n$ then $\mathcal{P}(A)$ has exactly $2^{n}$ elements.
Proof · one binary choice per element

To build a subset $X \subseteq A$, walk the $n$ elements of $A$ and for each decide: in $X$, or not in $X$. Two options, $n$ times, independently.

Every subset arises from exactly one such sequence of decisions, so there are $2 \times 2 \times \cdots \times 2 = 2^n$ of them. $\;\blacksquare$

Check it $|A| = 0$: only $\varnothing$, and $2^0 = 1$.  $|A| = 3$: the eight we listed, $2^3 = 8$.
Grows fast $|A| = 10$ gives $1024$ subsets; $|A| = 20$, over a million. Session 4 names this: exponential.
The bijection with binary strings is worth drawing: $\{1,3\} \subseteq \{1,2,3\}$ is $101$. That picture makes $2^n$ obvious rather than memorised, and it comes back in Session 7. Note the $n = 0$ case out loud — the empty set has exactly one subset, itself — because students expect zero and it is a classic exam slip.
Activity 4

Products and power sets

Activity 4pairs12 min
Let $A = \{1, 2\}$ and $B = \{a\}$.
  1. List $A \times B$ and $B \times A$. Are they equal? Justify from the definition of an ordered pair.
  2. List $\mathcal{P}(A)$ in full. How many elements does $\mathcal{P}(\mathcal{P}(A))$ have? Do not list it.
  3. Is $\mathcal{P}(A \cap B) = \mathcal{P}(A) \cap \mathcal{P}(B)$? Prove it or break it.

(1) Not equal: $(1,a) \neq (a,1)$. (2) $\mathcal{P}(A)$ has 4 elements, so $\mathcal{P}(\mathcal{P}(A))$ has $2^4 = 16$ — several pairs will try to list it and lose five minutes; let one of them, it teaches the point about growth. That asymmetry between (3) and (4) is the best thing in this activity — make sure it gets said out loud.
Watch out

The three ways today goes wrong

1 · Confusing $\in$ with $\subseteq$ Is $\{1\} \in \{\{1\},2\}$? Yes. Is $\{1\} \subseteq \{1,2\}$? Yes. Different relations, different questions.
2 · The diagram is not the proof A Venn diagram shows one configuration; the claim quantifies over all sets. Draw to guess, write the inclusion to prove.
3 · Forgetting $\varnothing$ $\varnothing \subseteq A$ for every $A$, vacuously. It is in every power set — and it is the case people drop when listing subsets.
The fix for all three Go back to the definition and read it as a sentence about an arbitrary element. All three errors come from reasoning off the shape of the notation instead.
All three are the spec's pitfalls, and each has already appeared today — call back to where. The unifying fix in the note box is the sentence to leave them with: when stuck, unfold the definition and talk about an arbitrary element. Two minutes; they are tired by now and this is a checklist, not new material.

Wrap-up

What today was actually about

  • A set is determined by what is in it — not by order, repetition, or the notation you wrote it in.
  • Every operation is a logical connective in disguise: $\cup$ is or, $\cap$ is and, $\setminus$ is and not.
  • Double inclusion proves an equality; one counterexample destroys one.
